| D1 | 核心循环 | **操作**：油门、升档、降档 3 个键；没有刹车；玩家不控制方向，车自动沿路走。**前 30 秒**：启动引擎 → 一档按住油门 → 看转速表在最佳点升档 → 第一个弯前松油门 + 降档，用引擎制动减速 → 听轮胎声过弯 → 出弯补油升档。**重复循环**：直道踩准换挡点推高速度 → 弯前判断何时松油、降几档 → 弯中靠分阶段的轮胎声判断离抓地极限多远 → 出弯加速 → 下一个弯。**减速手段**：松油门有明显减速（类似电车动能回收）；松油门同时降档，引擎制动叠加，减速更猛。**换挡贴近现实**：有扭矩曲线和最佳升档点；升早了动力肉，顶到红线速度升不上去；不做"完美换挡猛推"之类的街机式奖励。**三种失败**：(1) 弯中超过抓地极限 → 失控飞出去；(2) 红线断油后仍按着油门不升档 → 引擎爆掉；(3) 降档太快，转速被拉过红线 → 引擎爆掉。**重复的乐趣**：每个弯都能下次更晚松油、少降一档、更快通过；降档本身有风险，减速也要算计。 | user（"只换挡不转向"在 AI 给出的选项中由开发者选定；"油门无刹车"为 AI-suggested, confirmed） | 开发者说明：demo 先做不带刹车的版本看效果；如果玩起来奇怪或不舒服，再改成带刹车的版本。不做转向的理由（开发者）：控制 demo 体量；反打方向修正转向过度/不足只适合硬核玩家，不属于初心。 |
| D2 | 操控与镜头 | **设备**：只做键盘；手柄以后再说。**默认按键**：`空格` = 油门，`↑` = 升档，`↓` = 降档；支持改键位（例如改成左右键升降档）。**档位**：只有前进档，最低一档，档位数可以很多；没有倒档、空档、熄火键。**启动流程**：技术人员接好启动设备 → 玩家长按空格点火 → 松手，车通电、仪表显示一档，技术人员撤走设备 → 此后空格就是油门。**画面**：3D，第一人称，驾驶位在车正中间，没有副驾。**座舱可见物**：仪表台、方向盘（自动跟着弯道转）、驾驶员的双手、转速表和档位标识、头顶一部分车顶（暗示身处密闭空间）；看不到 A 柱（设定：新时代技术把 A 柱隐藏/透明化）。**手的动作**：手握方向盘；升档、降档时能看出手指在拨方向盘后面的换挡拨片。**透明座舱**：刚坐进去时环顾四周全黑，像没有玻璃一样；点火后前方像显示屏一样"歘"地变透明，外面一览无余。**车内滤镜**：透过座舱看到的外部世界带一层轻微滤镜或扭曲，与车外直接看到的景象有区别，让玩家知道自己还在车里。**仪表**：只有转速表 + 档位标识，不放速度表（速度感来自画面效果而不是数字）。 | user（键位方案 A、3D 为 AI-suggested, confirmed） | 范围提示：驾驶员双手的模型和拨片动画是座舱里最费工的部分。镜头随速度/弯道的动态（后仰、侧倾、视野拉伸）放在维度 6 手感里定。 |
| D3 | 规则与实体 | **玩家的车（星速跑车）**：沿路自动行驶；速度只由油门和档位决定；有转速、扭矩曲线、红线和断油。**路**：唯一的挑战来源，包含直道、各种急缓的弯、连续弯、发卡弯、上坡、下坡；上坡时加速变慢，下坡时松油减速的效果变弱；路上没有其他车和障碍物。**抓地极限**：每个弯按急缓有一个能通过的最高速度；接近极限时轮胎声分阶段变化；超过极限进入**挣扎区**——车往弯外滑、座舱剧烈抖动、轮胎尖叫，此时立刻松油或降档压低速度可以救回来；不处理或超得太多，滑出路外就飞出去失败。**引擎**：顶着红线断油太久，或降档把转速拉过红线，引擎爆掉失败。**HUD 小地图**：像车载抬头显示一样投影在挡风玻璃正中偏下，显示自己的位置和前方弯道走向，让不熟路的玩家能提前调整速度。**人物（CEO、保镖、技术人员）**：只在开场和结尾的剧情里出现，不参与驾驶玩法。 | user（挣扎区、坡道效果、人物仅剧情为 AI-suggested, confirmed） | 开发者："作为 demo 可以的。" 不放障碍的理由：玩家不能转向，躲不开任何东西。 |
| D4 | 胜负与进度 | **一趟的结束**：从基地出发，跑完绕地球一圈回到基地。**失败后**：赛道按地貌分成若干区段，进入新区段自动存档；飞出去或爆缸后回到当前区段起点，带着合理的初速度和档位继续。**不做总分、总等级和惩罚**（开发者："它并不是严格的竞速游戏"）。**区段贴纸/奖牌**：每完成一个区段，车上贴一枚对应该区段的贴纸（或挂奖牌），分塑料、铜、银、金四档，每个区段的图案不同；塑料档表示"开完了"。跑完一圈，车上的一排贴纸就是这趟旅程的成就证明。**贴纸等级的依据**：只看该区段最终成功通过那一次的用时，越快等级越高；失败后回到区段起点时计时重新开始，失败本身不扣任何东西。**跨次保留**：本机保存每个区段拿过的最高等级贴纸，在主菜单或车库里能看到这台车的贴纸收藏；再跑时成绩更好则贴纸升级；不保存中途进度，每次都从基地跑完整一圈；不能单独选段。**金牌区段的变化**：拿过金牌的区段，再次经过时换一套天空、光照和氛围（例如森林变成流星夜、冰山出现极光、城市变成霓虹夜景），场景模型不变，让重跑有新东西看。**排名**：不做联网排名，只在本机记录。 | user（存档点、用时定级、本机保留、金牌换天气和光为 AI-suggested, confirmed；贴纸收集的整体方案为 user） | 开发者的要求：因为不能单独选段，中间过程必须足够好玩、风景足够美，让重跑不枯燥。金牌变化的具体内容（每段换成什么天气和光）在维度 5 / 7 里定。 |
| D5 | 关卡/场景 | **开场**：一屏邀请函图文 → 直接切到车内视角（已坐在漆黑的座舱里）；CEO 的介绍和台词"这辆车是为速度而生，它不是为了减速的"以字幕形式出现，按空格推进 → 长按空格点火，座舱变透明，看到车库 → 开出车库。**不做**走进公司、走进车库的过场动画（开发者："这中间动画就不要有了，直接在车里面开始就好了"）。**车库 = 大本营**：每次出发都从这里开始，也在这里看车上的贴纸收藏。**试车环道**：围着基地的小环道，含一条直道、一个缓弯、一个急弯；CEO 通过车内通讯逐步提示：油门和升档 → 松油降档减速 → 听轮胎声的几个阶段 → 故意进一次挣扎区再救回来；可以一直绕圈，这里失败没有代价、原地恢复；准备好后在岔路口开上主赛道；以后每次出发可以跳过环道。**主赛道**：基地 → 森林 → 冰原（冰山）→ 城市 → 回基地，共 3 个区段。每段约 1 分钟，大约 8–12 个弯加几条直道，各含一段能冲到极速的长直道、一组连续弯、一个发卡弯；整圈 3–4 分钟。**结尾**：开回车库，展示这一趟贴在车上的三枚贴纸。 | user（三个区段、每段 1 分钟、试车环道方案为 AI-suggested, confirmed；区段选择森林/冰原/城市为 user） | 以后扩展：优先加新地貌区段（海底、地心、山河湖海等），而不是加长现有区段；本次 demo 不做。区段顺序（森林→冰原→城市）是 AI 假定的，开发者未反对。点火后车库里是否能看到 CEO 等人物的静态造型，留到维度 7 美术里定。 |
| D6 | 手感 | 手感目标见下方"D6 手感目标与可调初始值"一节。开发者确认的是手感目标；数值全部是可调初始值。 | user（各项在 AI 给出的选项中由开发者选定或修改；镜头动态为 AI-suggested, confirmed） | 速度感的分层方案先试，效果不好再换"平滑渐变"或"全程夸张"。 |
| D7 | 美术风格 | **方向**：低多边形 3D 模型 + 像素化渲染（样张 E）。**渲染方式**：整个 3D 画面先以较低的内部分辨率渲染，再用最近邻方式放大成清晰的方块像素；颜色压到有限色板，渐变处用规则的抖动网点过渡。**像素化只是轻微的**（开发者："稍微有一点像素化，也不要这么糊"）：窗外世界的初始内部分辨率为 960×540（可调范围 800×450 到 1280×720；显得糊就提高，低模棱角显廉价就降低），样张 E 的 480×270 太粗，不采用。**座舱与世界分开处理，但两者都是像素化的**（开发者："里面是完全清晰的，外面完全像素化，那个很奇怪……里面的细节程度比外面细节程度更高"）：座舱、方向盘、双手、转速表也做像素化，只是颗粒比窗外更细、细节更多，初始内部分辨率 1280×720（可调；原则是座舱的像素始终比世界细一档，转速表的刻度和数字必须清晰可读）。里外颗粒度的差别同时承担 D2 里"隔着一层东西看外面"的车内滤镜效果。**造型**：形状夸张、棱角分明的低模；体积靠切面的明暗两色表现（每个面一个纯色，亮面和暗面各一色），不用贴图细节；物体带细描边，描边色为深蓝黑而不是纯黑，粗细约为内部分辨率下的 1 像素。**天空**：上下两色渐变，带抖动网点；云是白色的多边形块。**色板**：深蓝黑 `#1b2233`（描边、座舱、暗部）、朱红 `#ef4a2f`（跑车、手套、警示、座舱高光线）、金黄 `#ffc93c`（HUD、车道线、强调）、晴空 `#4fb8e6`（天空上部、冰）、森绿 `#2f9e6a` 与暗绿 `#23805a`（树的亮面/暗面）、草地 `#58b97a`、暖白 `#f7ecd4`（天空下部、高光）、路面 `#4a5262`、远山 `#6f9fc0`。**区段配色倾向**：森林以绿为主、天空晴蓝到暖白；冰原以白 `#f4fbff`、冰蓝 `#4fb8e6` / `#a5dcf2` 为主；城市以金黄天空 `#ffc93c`、路面灰 `#4a5262`、朱红与深蓝黑的楼体为主。**速度线**：白色、粗细不一的直线笔触，从画面消失点向外放射。**座舱**：深蓝黑的车顶和仪表台，仪表台上沿一条朱红细线；双手戴朱红色手套；拨片为朱红色。 | user（在五张样张中选定 E；像素化渲染的想法为 user 提出） | 开发者的理由：低模如果不做处理会显得廉价，像素化渲染把棱角变成风格。已排除：B 霓虹线框。样张文件在 `game-spec/samples/`，只是一次性参考，可以删除，不作为规格输入。待定：像素化会让极速时的拉线效果带颗粒、远处弯道更难看清，颗粒度需实机调整。车库里人物是否出现，见 D11。 |

## D6 手感目标与可调初始值

### 手感目标（开发者已确认）

1. **加速：一波一波往上叠。** 每个档位内，转速越接近最佳点推力越猛；升档瞬间推力短暂一顿，随后下一波再顶上来；升早了能明显感到动力发肉；顶到红线速度不再上升。
2. **速度感：分层升级。** 低档位画面正常、视野略宽；中段景物被拉长、视野明显拉伸、座舱轻微震动；最高几档进入"星速"状态——四周变成掠过的光线和色带，只有正前方一小块还看得清路，视野拉到极夸张，声音像被压住。每升一档，世界"变形"一级。
3. **减速：松油是"拖住"，降档是"一拳"。** 只松油门，车稳稳慢下来，但不够应付发卡弯；每降一档，身体前冲、转速跳起、引擎嚎叫、速度掉一大截；降得太急转速冲过红线会爆缸，要等转速落一点再降下一档，形成节奏。
4. **过弯余量：越来越窄。** 轮胎声第一段范围宽，第二段明显更窄，第三段（最快的过弯状态）很窄，挣扎区也很窄。早早就有提示，但贴住真正的极限需要很细的油门控制。
5. **镜头：** 加速时头往后仰、视野变宽；降档时头往前点；过弯时镜头向弯外侧倾并略微看向弯心；进挣扎区时整个画面往外甩并剧烈抖动。座舱始终清晰，外面越快越模糊。
6. **失败：狠，不用慢动作。** 抓不住飞出去、撞墙、一次夸张的大爆炸（爆缸同理：指针打到底、爆响）；之后屏幕慢慢变暗到全黑，显示 Game Over 和三个选项：从存档点继续、从头开始新的一圈、退出。爆炸之后可以按空格跳过，直接从存档点继续。

## 起草规格时要留意的事项（一致性检查结果）

1. **"没有刹车"是 demo 最大的手感风险**：发卡弯能不能靠"松油 + 连降档"刹住，取决于 D6 里减速相关的初始值；开发者已预留"不行就加刹车键"的后手（D1）。
2. **"贴近现实的换挡"与"arcade、不要模拟器"并存**：扭矩曲线、爆缸、降档过转都偏拟真。锚点明确不要模拟器感，规格里应保持规则简单、反馈夸张，不引入离合、热衰减等更多拟真系统。
3. **像素化与速度线、远处弯道可读性**：世界做了像素化后，景物拉线会带颗粒，远处弯道更难看清；HUD 小地图承担预告弯道的任务，颗粒度需实机调整（D7）。
4. **美术工作量集中在三处**：三个区段各自的多变体环境物、三套金牌版的天空与光、精致座舱加手和 3D 奖牌。区段内容每段约 1 分钟，注意不要在起草时扩张。
5. **仍为暂定、需实物验证的项目**：星速音乐风格（D9）、速度感分层方案（D6）、外星嗡鸣层（D9）、调音工具做成网页还是游戏内面板（D9）、网上找的手部模型的授权与风格对齐（D10）。
