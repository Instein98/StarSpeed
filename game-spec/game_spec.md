## 1. Overview and Intent Anchor

### 1.1 意图锚点（原文照录，含开发者的两次修订；只把标题层级下调了两级）

> 本文件记录开发者的原始想法与感受。开发者确认后即冻结，除非开发者明确要求修改原始想法，否则不再改动。后续评审以本文件为准判断规格是否忠实。

#### 想法（原话）

我今天想的是，做一个游戏 demo， 就是能够让玩家体验到驾驶乐趣，开车开得很爽那种乐趣的感觉。首先呢，操控方式呢，我想用的是一种手动挡，但它未必需要，就是一定要按现在真实的手动挡操作，比如说5速、6速变速箱的操作方式来操作。 它甚至可以变成自动化的。举个例子，不一定非得按这个搞，我只是提供一个思路、一个 option、一个想法。就是说我可以就按上键和下键嘛，按上键升档，按下键降档嘛，就这两个是玩家操控的，这样也是一种手动挡。 为什么要用手动挡呢？就是要让玩家有参与感、操纵的乐趣。就比如说我降档，我能听到引擎的轰鸣，加速度的增大，这样的话可以体验这个操作的乐趣、参与感。甚至可以摒弃这个油门的概念。就比如说一个按键用来启动和熄火，然后 用档位直接来操控起和停，甚至都不用刹车，没有刹车哎，我觉得不用刹车这个感觉非常的好。因为不用刹车的话，玩家就会有一种紧张感、刺激感，就是要失控的感觉。啊，就不用刹车，那我那就是要。 一定要保证这个车不失控，稳定不失控，对吧？停不下来嘛。这种感觉，我觉得可以加入游戏里面，有这种刺激感。好，我启动汽车，如果车在一档，它就直接开始加速了。就是这个车它自动会加速的，除非我到了倒档，它可能会减速到停，然后往后面加速。但是它是没有刹车这个功能的，就是说可能是一个。 prototype， 然后第二个就是体现极限操作的，我觉得是弯道，因为现实里面的话，跑山的乐趣的来源就是这个弯道，就是我到底多少的弯我能够，多少的速度我能过这个弯，现实里面的话，就是如果你用极限的速度过这个弯，你会有一种。 爽快的感觉啊，就好像，就是在极限边缘游走嘛。所以我觉得这个游戏里面要加一个功能，就是你这个车赶紧要失控的时候，你必须要能听到这个声音，轮胎的声音，吱吱吱吱的声音。你甚至失控的阶段不一样，就快失控的这个警告，甚至有3种不同的声音。比如说刚开始轮胎已经接近。 刚开始离这个轮胎的极限还有一段距离，他可能听到是一种声音，然后马上到极限了，可能又是听到另一种声音，然后玩家就会想办法让这个车，哎，在马上到极限的这个速度上面去过弯，这样能够达到最快的速度，最快的过弯速度。这是第二点。 第三点就是加速，直线加速的爽感。这个爽感的话，我觉得已经很俗套了。我们想想看有没有什么办法可以做出更加新意？就一定要是玩家就是感觉是很爽，不管是高速过弯、极限过弯，还是说超级快的加速，对吧？它可能加速极速到了非常高的地步了。 那他这个时候，他可能看到周围景色已经模糊了，快到已经模糊了，甚至已经看不清楚是什么东西了，只能看到一个个线条，就快到这种程度。然后可能视角也会随着放大和缩小，缩到一种极限非常夸张的程度，就是要让玩家一种超级夸张的方式来体验这种感觉，速度感觉。然后这个 prototype 呢，我想把这个流程做的比较简单，大概的故事背景呢，就是你这个主角就是这个地球上存在的这个飞车传奇啊，传奇赛车手啊，然后是地球上面排名第一的 legendary 的啊，就好像篮球界的乔丹。 PUA 界的 mystery 啊，是家喻户晓的传奇明星、传奇驾车明星。然后这个汽车公司呢，啊，汽车公司他们造了一台，啊，他们通过引用外星科技，造了一台，啊，星速跑车啊，他们管这个叫。 星速跑车啊，就是以外星科技来做的这个加速能力啊，他们做了一个 prototype， 然后想让你来做测试然后这个啊，它的场景可能是就是。 你可能收到了邀请函，收到一份邀请函，上面邀请你过去测试。然后到了现场之后，公司的 CEO 和他的保镖就过来，就开引领你去他们的实验室，其实是一个实验性的车库，然后给你售了这一台超级跑车。然后他跟你说一句话，他说："这辆车是为速度而生，它不是为了减速的。" 所以这辆车没有刹车，我们想让你世界上最强的赛车手、最伟大的赛车手来测试一下这辆车性能。然后他就上车，然后可能先在某个小场地熟悉一下操作之后，然后就带你到了一个，就开始告诉你一个赛道，让这个赛道呢很长很长很长，甚至。 这个赛道呢，它是环绕整个地球一圈，啊，它可能穿越冰山、穿越森林、穿越山河湖海，甚至进入海底，然后穿越城市，啊，穿越什么地方，啊，甚至穿越地心，就各种地方全都穿越一遍，对吧？你就是要在这条路上面尽可能的发挥这辆车的极限，啊，并且不会开坏，不会出问题。 然后就让玩家感觉到哇，好爽啊！绕地球一圈，而且开的过程如此的痛快爽快啊！然后就是让玩家感觉最后回到了一圈，回到了这个基地，啊，最后会给你的表现进行打分或者排名之类的。反正我的初心追求目的就是让玩家感觉到一种非常爽的感觉啊！ 极致的速度感，极致的爽感，这就是这个游戏的目标。游戏 demo 想要体现的东西，想要展现的东西，看看能把这个概念展现成什么样子，就是这个游戏的最终目标。

##### 开发者明确要求的修订（2026-11-13，冻结后）

开发者发现原设定的漏洞："如果车的设定是自动加速……那降档其实也没有办法把车速降下来。"因此修订如下，其余原话不变：

- **增加一个油门键**：车不再自动加速；按住油门加速，松开油门车会明显减速（类似电车动能回收的感觉）。
- **仍然没有刹车**："没有刹车"的设定和 CEO 的台词保留。减速靠"松油门 + 降档的引擎制动"。
- 开发者原话："就是做的更现实一点，就是说我降档如果降的特别快，我可能会撑爆红线，因为每次降档的时候它会把转速拉高嘛，我降的太快的话，它也有可能撑爆红线导致发动机爆炸，这个我也要加进来。"

##### 开发者明确要求的修订（2026-11-14，审阅规格初稿时）

- CEO 的台词改为："这辆车是为速度而生，所以它没有刹车。"（原话是"这辆车是为速度而生，它不是为了减速的。"）

#### 感受

- **爽**：极致的速度感、极致的爽感；开车的速度爽感 + 操纵的快感。
- **紧张、刺激、停不下来**：没有刹车带来"要失控"的感觉，神经紧绷。
- **在极限边缘游走**：贴着轮胎抓地极限过弯的爽快。
- **参与感、全神贯注、心流**：靠换挡亲手操控，降档听到引擎轰鸣、感到加速度增大。
- 已经能想象到的画面：
  - 极速时周围景色模糊到看不清，只剩一条条线条，视野夸张地拉伸缩放。
  - 快到极限的弯道里，轮胎吱吱叫，声音随接近极限的程度分阶段变化，玩家努力把车稳在"马上到极限"的速度上。
  - 降档的一瞬间，引擎轰鸣、加速度猛增。
  - CEO 在实验车库里说："这辆车是为速度而生，它不是为了减速的。"

#### 参考

- **《Redline》（动画电影）**：开发者只看过片段；借的是那种非常夸张的极速表现感。
- **CAR GAME（adam pype，https://papercookies.itch.io/car-game ）**：一个非常简单的手动挡开车小游戏，带一点 arcade 风格；借的是"简单的手动挡操作本身就是乐趣"的做法。

#### 不想要

- 不要变成非常无聊的模拟器。
- 不要《极品飞车》或 Forza Horizon 那种感觉。
- 绝对不要 Assetto Corsa 那种 simulator 的感觉。
- 只要 arcade 风格的开车游戏。

#### Demo 目的

把"速度的爽感"和"开车操纵的爽感"这个概念在游戏里推到极限，看看能推到什么程度。

成立的标准（开发者亲自玩完后的感受）：非常有参与感、非常爽、神经紧绷、全神贯注、进入心流；既有速度的爽感，又有操纵的快感。有这种感觉，这个概念和这个 demo 就算成立。

### 1.2 玩家视角的描述

你坐在一台没有刹车的外星科技跑车正中间，面前是方向盘，但你不用转向——车自己沿着路走，你只管三个键：油门、升档、降档。直道上你盯着转速表，在指针进红区之前一档一档往上拍，车越快世界变形得越厉害（随车速连续变化），到约 420 km/h 时窗外所有东西都碎成一根根飞掠的线，音乐随速度渐渐浮上来。弯道来了没有刹车可踩，只能松开油门、掐着转速一档一档往下降，让引擎把车拖慢，降得太急引擎当场爆掉。弯里你闭着眼都能听出轮胎的三种叫声，把车稳在最尖的那一种上，就是最快的过弯速度；再快一点车就往外甩，甩出去就是一次大爆炸。跑完森林、冰原、城市回到车库，车窗右上角多了三枚奖牌贴纸。

## 2. Demo Scope

### 2.1 做（In）

1.  标题画面（开始、键位设置、语言、退出），背景里展示已获得的贴纸。
2.  开场：一屏邀请函 → 漆黑座舱里的 CEO 字幕（含台词"这辆车是为速度而生，所以它没有刹车。"）→ 长按油门键点火 → 座舱前方变透明、看到车库。
3.  车库：点火后能看到 CEO、保镖、技术人员三个静态造型（不动）。
4.  试车环道：围着基地的闭合小环道，教学（步骤 0–4 共五步）；首次必须完成教学，之后每次出发可以跳过。
5.  主赛道：森林 → 冰原 → 城市三个区段，首尾相接，终点回到基地。
6.  驾驶：油门、升档、降档三个键；8 个前进档；车自动沿路行驶。
7.  引擎模型：转速、扭矩曲线、红线、断油、升档动力中断、松油与降档的引擎制动。
8.  抓地模型：每个弯的极限速度、轮胎声三段、挣扎区。
9.  三种失败：冲出赛道、顶红线过久爆缸、降档过转爆缸；失败演出（爆炸、渐暗）和 Game Over 菜单。
10. 区段存档点：进入每个区段时自动存档；失败后从该区段起点线之前 3 秒的位置自动回放当时的进场过程，屏幕倒计时 3、2、1，越线时把控制权交还玩家。
11. 速度感分层：世界和座舱的视野拉伸、景物径向拉线、座舱震动；车速越高越强：从 7 档 4500 转左右（约 285 km/h）开始，窗外景物一点点被拉长，到约 420 km/h 全部变成流动的线（"星速"），没有按档位触发的切换。
12. 仪表与 HUD：圆形转速表（含档位数字和换挡提示灯）、挡风玻璃上的全息投影小地图；没有速度表。
13. 区段奖牌贴纸：塑料、铜、银、金四档，按该区段成功通过那一次的用时评定；以贴纸的形式出现在挡风玻璃右上角，三枚从上到下排列。
14. 本机存档：每个区段的最高贴纸等级、教学是否完成、开场是否看过、键位、语言、辅助开关、混音参数。
15. 金牌区段变化：拿过金牌的区段，下次经过时换一套天空、光照、氛围和色板。
16. 暂停菜单、改键位界面、结尾画面。
17. 音频：真实录音分层的引擎声和轮胎声、风声、星速音乐、标题与车库的氛围音乐、界面与演出音效。
18. 调试工具：游戏内的引擎混音面板（设置保存到本机，下次启动沿用）、调参热加载、调试信息（含轮胎状态显示）、星速画面方案切换。
19. 界面语言：简体中文和英文，能在标题画面切换。
20. 辅助开关：降档提示灯（键位设置里开关，默认关）。
21. 交付顺序：先做操作、声音、速度感的最小可玩版本（出库路、环道、森林区段，无模型）；冰原、城市、贴纸、金牌版、结尾放补充阶段；模型数量严格受限（第 8.4a 节）。

### 2.2 不做（Out）

1.  刹车键、转向、倒档、空档、离合、熄火键。
2.  手柄、方向盘外设、鼠标驾驶操作。
3.  海底、地心、山河湖海这些区段；单独选段重跑。
4.  路上的其他车、障碍物、可拾取物。
5.  不同路面的抓地差异（冰原的抓地力与森林、城市相同）；轮胎磨损、温度、油耗、损坏累积。
6.  走进公司和车库的过场、人物动画、人物配音、对话选项。
7.  速度表、圈速表、驾驶中持续显示的计时器、总分、总评级。
8.  联网排名、成就系统、多存档位。
9.  "完美换挡"奖励、氮气、漂移得分。
10. 车的外观模型（全程第一人称，镜头不离开座舱）；驾驶员双手的模型；换挡拨片（模型和动作）；精细的 3D 奖牌及其展示演出。
11. 动态阴影、昼夜渐变、天气粒子对驾驶的影响（金牌版的流星、极光、霓虹只是视觉）。
12. 简体中文和英文以外的语言。

### 2.3 完成标准（Done when）

开发者自己从邀请函一路玩到回车库，跑完一整圈并拿到三枚奖牌，过程中觉得非常有参与感、非常爽、神经紧绷、全神贯注、进入心流，既有速度的爽感又有操纵的快感。

## 3. Core Loop and Rules

### 3.1 前 30 秒（首次游玩）

| 时间 | 玩家做什么 | 看到、听到什么 |
| :-- | :-- | :-- |
| 0 s | 在标题画面选"开始" | 邀请函一屏 |
| 3 s | 按油门键 | 画面切到漆黑座舱，只能看到转速表的微光和 CEO 字幕 |
| 3–15 s | 按油门键逐条推进 5 条字幕 | 第 3 条是"这辆车是为速度而生，所以它没有刹车。" |
| 15 s | 长按油门键 1.5 秒（T-50） | 转速表指针随长按扫到尽头再落回怠速；引擎启动声；前方"歘"地变透明，看到车库、三个人物和敞开的大门；档位显示 1 |
| 18 s | 按住油门键 | 车向前冲出车库，引擎声随转速升高 |
| 20–24 s | 每次指针到 7800 转时按升档键，升到 3–4 档（出库路只有 700 m，全油门冲到底会超过第一个弯的极限速度；教学里失败只是原地恢复） | 每次推力一顿，转速落下，下一波推力顶上来 |
| 24 s | 前方是环道缓弯；松开油门 | 引擎声变闷，车被拖慢 |
| 26 s | 等指针落下后按降档键，重复几次 | 每次引擎嚎一声，转速跳起，身体前冲，速度掉一截 |
| 30 s | 进弯，听轮胎声 | 低沉摩擦声 → 吱吱声 |
| 34 s | 出弯，按住油门、升档 | 进入重复循环 |

### 3.2 重复循环

1.  **直道**：按住油门，每个档位在 7800 转（T-06）升档，把速度推高。
2.  **弯前**：看小地图判断弯的急缓，决定何时松油、降几档；每次降档前等转速落到安全范围。
3.  **弯中**：靠轮胎声判断离抓地极限多远，用点按油门把速度稳在第三段声音上。
4.  **出弯**：按住油门，升档，回到第 1 步。

每个弯下次都能更晚松油、少降一档、更快通过；区段用时决定奖牌等级。

### 3.3 行驶规则

*   **R-01** 车的位置只由沿赛道中心线的里程 `s` 决定。玩家没有任何改变方向的输入。
*   **R-02** 转速由车速和档位唯一确定：`rpm = max(T-03, v ÷ 当前档断油车速(T-02) × T-05)`。没有离合，没有空转。
*   **R-03** 按住油门、不在换挡中、且 `rpm < T-05` 时：加速度 = 当前档峰值加速度（T-08）× 扭矩系数（T-07，按 rpm 查曲线）× 坡道系数（R-10）。
*   **R-03a** 轮胎吃力：ratio ≥ T-22（第一段起点）时，R-03 的加速度再乘 T-57。轮胎已经在吃侧向力，给不出全部驱动力；这让点按油门能把车停留在第三段轮胎声里，不必每秒连点 3–5 次。松油门的减速不受影响。
*   **R-04** 松开油门时：减速度 = 引擎制动（T-13、T-14，按 rpm 查曲线）× 坡道系数（R-10）。车速最低为 0，不会倒退。车速为 0 时车静止不动，直到再次按住油门。
*   **R-05** 升档：档位 +1；之后 T-09 秒内加速度为 0（既不加速也不减速），转速表指针在这段时间内从旧转速扫到新转速。在 8 档按升档键无效，只播放"拒绝"音（S-34）。
*   **R-06** 降档：先按降档前的车速（未扣掉 T-15 / T-58 的损失）算出降档后的转速 `rpm'`。若 `rpm' > T-12`，引擎立即爆缸（失败 3）。否则档位 −1，转速表指针在 T-10 秒内扫到新转速，这 T-10 秒内加速度为 0。此外分两种情况：
    *   **松着油门降档**（减速用）：车速在这 T-10 秒内均匀损失 T-15 的比例；之后按 R-04 以新转速的引擎制动继续减速。这就是"一拳"。降档在转速表上没有任何标记，什么时候能降要靠经验和耳朵（引擎声会告诉你转速）；想要提示的玩家可以在设置里打开 R-06a 的辅助灯。
    *   **按着油门降档**（找动力用，现实里的"补油降档"）：车速只损失 T-58 的比例（比"一拳"轻很多，车只是微微一顿）；T-10 结束后立即按 R-03 以新转速的推力加速，镜头向后仰一下。从低转速降到高转速，推力明显变大。
    *   在 1 档按降档键无效，播放"拒绝"音。
*   **R-06a** 降档提示灯（新手辅助，设置里的开关，默认关，保存到存档）：每帧用 R-06 同样的算法计算"现在降一档的 `rpm'`"（按降档前车速）；1 档、换挡进行中时灯熄灭；开启后转速表档位窗右侧亮一个晴空蓝小圆灯（直径为表盘半径的 8%），在降一档后转速 `rpm' ≤ T-59` 时点亮，否则熄灭；关闭时这盏灯不存在。
*   **R-07** 换挡进行中（T-09 或 T-10 期间）再按换挡键，缓存最后一次输入，当前换挡结束后立即执行；缓存深度为 1。
*   **R-08** 断油：`rpm ≥ T-05` 且按住油门时，加速度为 0，车速保持不变，播放断油限速声（S-06）。松开油门则按 R-04 减速（转速高于 9000 时引擎制动按 9000 转的值，不再增大）。8 档同样断油。只要 `rpm ≥ T-05`（不论是加速顶到的，还是降档后落在 9000–9400 之间），转速表指针都停在表盘尽头并在 8700–9000 之间以 12 Hz 抖动。
*   **R-09** 过转计时器：1–7 档 `rpm ≥ T-05` 时每秒 +1 秒；否则每秒 −2 秒，最低为 0。计时器达到 T-11 时引擎爆缸（失败 2）。**8 档不计时**：8 档顶到断油只是车速不再上升、换挡提示灯爆闪、升档键无效，不会爆缸。
*   **R-09a** 换挡提示灯：`T-18 ≤ rpm < T-05` 时以 6 Hz 闪烁，提示该升档了；`rpm ≥ T-05` 时爆闪，频率随过转计时器从 12 Hz 线性升到 20 Hz（8 档固定 12 Hz），断油声的音高同步升高 0–3 个半音，让玩家听得出、看得出离爆缸还有多久；其余时间熄灭。
*   **R-10** 坡道：赛道每一段有坡度。平滑后的坡度（R-11 的同一个窗口）≥ +3% 时为上坡，R-03 的加速度乘以 T-16；≤ −3% 时为下坡，R-04 的减速度乘以 T-17；其余为平路，系数为 1。

### 3.4 抓地规则

*   **R-11** 有效曲率 `κ(s)`：取赛道原始曲率（直道为 0，圆弧为 ±1/半径，左正右负）在 `[s − T-21, s + T-21]` 区间内的平均值。同样的平均用于坡度。
*   **R-12** 弯道极限速度 `v_lim = sqrt(T-20 ÷ |κ|)`；抓地比 `ratio = v ÷ v_lim`。`|κ| < 0.0001` 时 ratio 视为 0。
*   **R-13** 抓地分区（只由 ratio 决定）：

    | 分区 | ratio 范围 | 轮胎声 | 车的表现 |
    | :-- | :-- | :-- | :-- |
    | 安静 | < T-22 | 无 | 正常 |
    | 第一段 | T-22 – T-23 | S-10 低沉摩擦声 | 正常 |
    | 第二段 | T-23 – T-24 | S-11 持续吱吱声 | 座舱轻微高频震动 |
    | 第三段 | T-24 – 100% | S-12 尖锐发颤的啸叫 | 座舱震动加大，方向盘轻微抖动 |
    | 挣扎区 | 100% – T-25 | S-13 刺耳尖叫 | 车向弯外侧横移，画面外甩，剧烈抖动 |
    | 飞出 | > T-25 | — | 立即失败 1 |

*   **R-14** 挣扎计时器：在挣扎区内每秒 +1 秒；不在挣扎区时每秒 −2 秒，最低为 0。达到 T-26 时失败 1。
*   **R-15** 外滑量：等于 `挣扎计时器 ÷ T-26 × T-27`（米），方向指向弯外侧，只影响镜头位置和小地图上自车的位置，不影响里程 `s` 和 ratio。
*   **R-16** 从挣扎区救回：ratio 回到 100% 以下即离开挣扎区（这条分界没有回差），轮胎声立即切到第三段；外滑量随计时器回落而回到 0。第 5.3 节的 0.5 个百分点回差只用于安静、第一段、第二段、第三段之间的声音切换。

### 3.5 失败

| 编号 | 名称 | 触发条件 | Game Over 上显示的原因 |
| :-- | :-- | :-- | :-- |
| 失败 1 | 冲出赛道 | R-13 的 ratio > T-25，或 R-14 的计时器达到 T-26 | 冲出赛道 |
| 失败 2 | 顶红线爆缸 | R-09 的计时器达到 T-11 | 引擎爆缸：顶着红线太久 |
| 失败 3 | 降档过转爆缸 | R-06 的 `rpm' > T-12` | 引擎爆缸：降档太急 |

*   **R-20** 主赛道上失败：播放失败演出（第 7.3 节），随后显示 Game Over 菜单。从爆炸开始的那一刻起，屏幕下方一直显示失败原因（第 9.8 节），直到重新获得控制。爆炸开始 0.5 秒后按油门键，跳过剩余演出，直接执行"从存档点继续"。
*   **R-21** "从存档点继续"（进场回放）：车被放回"本趟第一次越过当前区段起点线之前 T-56 秒"所在的位置，然后自动重放当时记录下来的这一段（车速、档位、油门开合逐帧照搬）。回放期间玩家不需要按任何键，驾驶输入被忽略，不判定任何失败。屏幕正中依次显示 3、2、1，各 1 秒。回放结束的那一刻车正好越过区段起点线：倒计时消失，控制权交还玩家，车速和档位就是当时越线的车速和档位，该区段计时器从 0 开始，过转计时器和挣扎计时器为 0。之前区段已经拿到的成绩保留。画面在回放开始的 0.5 秒内从黑淡入。
*   **R-21a** 进场记录：行驶中始终保留最近 T-56 秒的逐帧记录（所在路径、里程、车速、档位、油门、驶出开关状态 `exit_armed`）。回放期间所有"看前方"的查询用记录里的 `exit_armed`；森林的进场记录因此在环道 L1 上、开关为"打开"（前方是森林 F1）。车头越过某个区段起点线时，把这段记录存为该区段的进场记录；本趟内同一区段只存第一次。用调试键 F4 跳到某区段时没有记录，改用 T-54 的车速和档位合成一段匀速记录。
*   **R-22** "重新开始一圈"：回到车库，已点火、1 档、车速 0；本趟各区段的成绩和进场记录清空（本机保存的历史最高等级不受影响）。
*   **R-23** "退出"：回到标题画面。
*   **R-24** 试车环道上失败（含通往环道的出库路）：没有爆炸和 Game Over。画面白闪 0.3 秒，车在原地恢复：里程不变，速度按 T-55，档位取使转速落在 4000–7000 之间的最低档，两个计时器清零。
*   **R-25** 失败不扣任何东西；没有生命数，没有次数限制。

### 3.6 区段、计时与奖牌

*   **R-30** 主赛道分为森林、冰原、城市三个区段，各有一条起点线和一条终点线；前一区段的终点线就是后一区段的起点线。
*   **R-31** 车头越过区段起点线时：自动存档点更新为该区段；按 R-21a 保存进场记录；该区段计时器从 0 开始。
*   **R-32** 车头越过区段终点线时：该区段计时器停止，按 T-53 的门槛评定贴纸等级（塑料、铜、银、金）。跑完就至少是塑料。
*   **R-33** 评定后：若等级高于本机保存的该区段最高等级，立即写入存档，挡风玻璃上该区段的贴纸换成新等级。贴纸出现的演出不暂停驾驶（第 9.6 节）。
*   **R-34** 驾驶中不显示计时器；用时只在贴纸出现时给出。
*   **R-35** 越过城市终点线 = 跑完一圈：输入锁定，车保持越线时的车速继续直行，画面 1.0 秒白化，切到结尾画面（第 6.7 节）。城市的贴纸不在这一刻演出，改在结尾画面里出现。
*   **R-36** 不保存中途进度。退出到标题后再"开始"，总是从车库出发。
*   **R-37** 金牌变化：出发时（离开车库的那一刻）读取存档；某区段的保存等级为金，则本趟该区段使用金牌版环境（第 6.6 节）。本趟中途新拿到的金牌，下一趟才生效。

### 3.7 试车环道规则

*   **R-40** 环道是闭合的，里程循环；只要不驶出就能一直绕圈。
*   **R-41** 驶出开关：在出库路和环道上按"确认"键（默认回车）切换路线。开关关闭时车在岔路口沿环道继续绕圈；打开时在岔路口直行驶入主赛道。车距岔路口不足 100 m 时开关锁定，按键无效并播放 S-34，过了岔路口再生效。每次从车库出发（含"重新开始一圈"）开关都是关闭的。岔路口前 220 m 处立着一块大的 3D 标志牌（A-25），关闭时写"按 [回车] 驶出"，打开时变为一个指向主赛道的大箭头并亮起。打开时小地图上岔路口也显示箭头，并播放 S-35；再按一次关闭。
*   **R-42** 首次游玩（存档里"教学完成"为否）时，驶出开关在教学（步骤 0–4）全部完成前不可用，按确认键无反应。教学完成后写入存档。
*   **R-43** 之后每次出发，驶出开关从点火后就可用；出库后直行 700 m 就到岔路口，打开开关即可不绕环道直接上主赛道。
*   **R-44** 环道上不计时、不发贴纸。

### 3.7a 赛道设计约束

*   **R-45** 每个区段至少有一条直道，正常驾驶时能在上面把车速开到 350 km/h 以上（进入星速）。
*   **R-46** 每条区段起点线前至少 400 m、后至少 300 m 是直道，保证进场回放和交还控制都发生在直道上。
*   **R-47** 任何直道的长度都不足以让 8 档顶到断油：全程不犯错的驾驶，最高车速不超过 8 档断油车速的 92%。如果试玩中在某条直道上 8 档到了断油，说明这条直道太长，应缩短直道，而不是改规则。
*   **R-48** 起点线之后的第一个弯必须救得回来：以该起点线上可能出现的最高车速越线，然后只靠松油和不过转的连续降档，必须能在第一个弯前把车速降到该弯的极限以内。本规格的三条起点线已用模拟核对（森林按 460 km/h、冰原按 600 km/h、城市按 540 km/h 越线，都救得回来）。改动赛道时要重新核对。

### 3.8 每种结束情况下重置和保留的内容

| 情况 | 重置 | 保留 |
| :-- | :-- | :-- |
| 环道失败 | 速度、档位、两个计时器 | 位置、教学进度 |
| 进场回放结束 | — | 交还控制，一切按第一次越线时的状态 |
| 主赛道失败后从存档点继续 | 位置回区段起点线前 T-56 秒处并回放进场；两个计时器、该区段用时清零 | 越线时的车速和档位与第一次相同；本趟之前区段的成绩、本机最高等级 |
| 重新开始一圈 | 位置回车库、本趟成绩、进场记录 | 本机最高等级、教学完成、键位、语言 |
| 跑完一圈 | — | 本机最高等级已在各区段终点写入 |
| 退出游戏再进入 | 一切本趟状态 | 存档文件里的全部内容 |

### 4.3 镜头

**世界摄像机**

| 项目 | 规则 |
| :-- | :-- |
| 类型 | 第一人称，固定在驾驶员眼睛位置，无自由视角 |

| 后仰 / 前点 | 加速时向后仰，角度 = 当前加速度 ÷ 14 m/s² × T-33；降档时在 0.25 秒内向前点 T-34 再回正 |
| 侧倾 | 向弯外侧倾，角度 = min(1, ratio) × T-35，方向由 κ 的正负决定 |
| 转头看弯 | 像真人开赛道一样，快到弯时头慢慢转向弯里。触发按距离，不按时间：前方最近一段圆弧的入口进入 T-39 的距离之内时开始转头。目标方向：入弯前和弯的前半段看向这段圆弧的弯心点（圆弧中点处的路面中心）；过了弯心点之后看向这段圆弧的出口；出弯后回正。转头角 = 目标点相对车头方向的水平夹角，限制在 ±T-36 之内。头以不超过 T-39a 的角速度匀速转过去，不会一下子甩过去。连续弯里目标依次切到下一段圆弧，头同样按 T-39a 慢慢转过去 |
| 挣扎区 | 水平朝向向弯外侧甩 T-38，并叠加 T-37 的挣扎震动 |
| 平滑 | 后仰、侧倾用 0.15 秒时间常数的指数平滑；转头看弯按 T-39a 限速，再加 0.1 秒时间常数的平滑去掉起止的顿挫 |
| 近、远裁剪面 | 世界摄像机 0.3 m / 4000 m；座舱摄像机 0.03 m / 10 m（方向盘离镜头只有 0.32 m，不能裁掉） |

**座舱摄像机**

| 项目 | 规则 |
| :-- | :-- |
| 位置 | 座舱模型内的驾驶员眼睛位置（座舱坐标原点上方 1.05 m） |
| 视野 | 按车速查 T-47 的表，以 T-31 平滑；变化幅度小于世界摄像机，这样座舱也跟着速度"撑开"，但转速表始终清晰可读 |

| 点火前环顾 | 不支持自由环顾；点火前座舱窗外全黑，由"世界画面不显示"实现 |

## 5. Entities

全游戏不使用物理引擎的碰撞检测。车在赛道曲线上按里程移动，所有"碰撞"（冲出赛道、越线）都由里程和 ratio 的数值判断得出。环境物只是布景，不可碰撞。

### 5.1 星速跑车（玩家）

用途：玩家唯一操控的东西。只有座舱内部可见，没有外观模型。

| 状态 | 进入条件 | 行为 | 离开条件 |
| :-- | :-- | :-- | :-- |
| 未点火 | 流程进入点火提示（开场字幕结束，或开场已看过时在标题选"开始"） | 世界画面不显示（窗外全黑）；转速表只有微光；档位不显示；车不动 | 长按油门满 T-50 |
| 点火演出 | 长按完成 | 1.2 秒：引擎启动声 → 指针落到 T-03 → 世界画面揭开（第 8.5 节 V-01）→ 档位显示 1 | 演出结束且油门键松开过一次 |
| 行驶·加油 | 按住油门 | R-03 | 松开油门；开始换挡；rpm ≥ T-05 |
| 行驶·松油 | 松开油门 | R-04 | 按住油门；开始换挡 |
| 换挡中 | 按升档或降档键且合法 | R-05 或 R-06 | T-09 或 T-10 结束 |
| 断油 | rpm ≥ T-05 且按住油门 | R-08、R-09 | 松开油门；换挡 |
| 挣扎 | ratio 在 100% – T-25 | R-14、R-15；可与上面任一行驶状态同时存在 | ratio < 100%；或失败 1 |
| 进场回放 | R-21 | 自动重放进场记录；输入忽略；不判定失败 | 越过区段起点线 |
| 失败演出 | 失败 1、2、3 | 输入锁定，播放第 7.3 节演出 | 演出结束或被跳过 |
| 锁定 | 越过城市终点线；暂停；Game Over | 输入忽略 | 对应界面关闭 |

状态变化的可见反馈：见第 7.3 节反馈表。

### 5.2 引擎（跑车的一部分）

用途：把"油门 + 档位"变成加速度、转速和声音。

*   输出给仪表：rpm、档位、换挡提示灯状态。
*   输出给音频：rpm、油门开或关、换挡事件、断油状态。
*   转速表指针显示的是经过 0.04 秒平滑的 rpm；换挡扫动和断油抖动直接驱动指针，不经平滑。
*   档位数字在换挡开始的那一帧就变成新档位。

### 5.3 轮胎（跑车的一部分）

用途：把"车速 + 弯道曲率"变成声音分区和挣扎状态。分区规则见 R-13。分区之间是切换，不是渐变：切换时旧声音在 30 毫秒内淡出，新声音在 30 毫秒内淡入。为了避免在分界线上来回抖动，从高分区回到低分区时要求 ratio 低于分界值 0.5 个百分点才切换。

### 5.4 赛道

用途：唯一的挑战来源。

*   由三条路径组成：出库路、环道、主赛道（第 6 节给出每一段的数据）。
*   每条路径是"直道"和"圆弧"首尾相接的序列；每一段带一个坡度值。
*   路面宽 12 m，无横向倾斜。
*   路面外观：路面色 `#4a5262`；两侧各一条 0.3 m 宽的金黄 `#ffc93c` 实线，距路缘 0.5 m；中央一条暖白 `#f7ecd4` 虚线，每段长 6 m、间隔 12 m、宽 0.25 m。
*   路面抬高处：森林和冰原的坡道两侧有 45° 的路基斜面一直落到地面，颜色 `#363d4b`。城市的抬高段（C9 – C13）是高架：没有路基，路面下方是桥墩（A-44），路面两侧各有一道 0.8 m 高的楼灰色护墙。
*   护栏（A-50）：所有半径 ≤ 300 m 的圆弧外侧，距中心线 6.5 m，覆盖圆弧全长并向前后各延伸 30 m；底面跟随路面高度。
*   弯道箭头牌（A-51）：所有半径 ≤ 150 m 的圆弧外侧，距中心线 8 m，每 15 m 一块，箭头指向转弯方向；底面跟随路面高度。
*   路口例外：护栏、箭头牌里，任何一个与另一条路径（或同一路径上里程相差 100 m 以上的另一处）的中心线距离不足 9 m 的，都不放。这样岔路口和出库路并入口的路面上不会有东西横着。
*   路口的路面：两条路面在岔路口和并入口重叠的范围内，只画主直道（L1 及其延长线 F1、P1）的车道线，另一条路的车道线在距主直道中心线 9 m 之内不画。
*   路上没有任何其他车和障碍物。

### 5.6 HUD 小地图（全息投影）

用途：让不熟路的玩家提前看到前方弯道的走向和急缓。

观感目标：像一块 3D 全息影像投在挡风玻璃上，而不是贴在屏幕上的一张平面图。玩家看它的感觉，是在第三人称追车游戏里从车后上方看一条向前铺开的路。

*   **位置**：挡风玻璃中下方，方向盘上缘的正上方，紧挨转速表（第 9.5 节给出坐标），不挡住正前方的主要视野。没有边框和底板。它像投在玻璃上一样跟着座舱走：转头看弯、座舱视野变化、座舱震动时，它与方向盘保持相对位置不变。
*   **视角**：设预看距离为 D（T-52）。虚拟摄像机在自车后方 0.15 D、上方 0.30 D，向前下方俯视 35°，垂直视野 50°，透视投影。近处的路宽、远处的路窄并向地平线收拢。车头永远朝画面深处。
*   **道路**：一条有宽度的路带（宽 0.03 D），两条金黄 `#ffc93c` 边线加 25% 不透明度的金黄填充；最远的 15% 渐隐到透明。坡道按真实高度的 3 倍画出起伏。
*   **急弯**：半径 ≤ 150 m 的圆弧那一段，边线加粗一倍。
*   **自车**：一个晴空蓝 `#4fb8e6` 的立体小箭头（有厚度的扁箭头），位于画面底部中央，尖端朝前；过弯时随方向盘转角左右倾斜。
*   **全息质感**：画面里只有路带和箭头，没有网格和底面；立体感来自透视（近宽远窄）、路带的起伏和箭头的厚度。整幅图像以加色方式叠在画面上（半透明、发光）；每 3 像素一条水平扫描线（该行亮度 −30%）；整体亮度以 8 Hz 做 ±5% 的闪动；线条外侧有 1 像素同色、40% 不透明度的光晕；图像整体呈上窄下宽的梯形（顶边宽度为底边的 80%），像投在倾斜的玻璃上。
*   **预看距离**：`clamp(v × 8 秒, 400 m, 1800 m)`（T-52），用 0.5 秒时间常数平滑；车越快，看得越远。
*   **区段线**：横跨路带的一条暖白亮线。
*   **环道岔路口**：两条路带都画出；驶出开关打开时，主赛道那一支的上方悬浮一个金黄色箭头。
*   **挣扎时**：自车箭头按 R-15 的外滑量向外偏移，并在朱红与晴空蓝之间以 10 Hz 闪烁。
*   **数据来源**：小地图画的路带、弯、坡、区段线、岔路口，全部直接取自 `track_data` 生成的同一张赛道采样表（和路面网格用的是同一份数据），不另外保存或推算一份几何，所以任何时刻它和真实赛道在形状、弯的位置、坡度上完全一致。
*   进场回放期间照常显示。

### 5.8 奖牌贴纸

用途：一个区段跑完的证明，也是重跑的目标。

*   **形式**：贴在挡风玻璃内侧右上角的圆形贴纸，像贴在车窗上的年检标。三枚从上到下：森林、冰原、城市。
*   **显示内容**：本机保存的各区段历史最高等级。没拿过的区段是空位：一圈金黄色的细虚线圆。驾驶中和标题画面显示的内容相同。
*   **模型**（A-09）做得简单：一个扁圆片（直径 7 cm）、一圈凸起的边、一个平的图案剪影。图案：森林 = 三棵松树，冰原 = 冰山和一颗星，城市 = 三栋高楼的天际线。
*   **材质**做得精致，四档明显不同：
    *   塑料：晴空蓝 `#4fb8e6`，哑光，没有高光。
    *   盘面 / 边圈的颜色：塑料 = 晴空 / 楼灰；铜 = 暗铜 / 铜；银 = 楼灰 / 银；金 = 金黄 / 暖白（边圈都比盘面亮一级）；图案剪影统一用深蓝黑；一条暖白高光带每 3 秒从左上到右下扫过一次（塑料没有）；压色板后高光带呈抖动网点。

## 6. Levels and Scenes

### 6.1 场景流程

```
标题画面
  │ 开始（存档里"开场已看过"= 否，或选了"重看开场"）
  ├──────────────► 邀请函 ──► 漆黑座舱 + CEO 字幕 ──┐
  │ 开始（开场已看过）                               │
  └────────────────────────────────────────────────► 点火提示（漆黑座舱）
                                                     │ 长按油门
                                                     ▼
                              车库 ──► 出库路 ──► 试车环道 ⟲
                                                     │ 驶出开关打开并经过岔路口
                                                     ▼
                              森林 ──► 冰原 ──► 城市 ──► 结尾画面 ──► 标题画面
```

整个驾驶部分是同一个 3D 世界，没有加载画面；标题、邀请函、字幕、Game Over、结尾都是叠在上面的界面。

### 6.2 坐标与赛道生成规则

*   赛道平面坐标：x 向东，y 向北，单位米；高度 z 向上。对应 Godot 坐标 `(x, z, −y)`。车库里车的位置是原点 `(0, 0)`，车头朝北。
*   每条路径从给定的起点和朝向出发，按下面各表从上到下逐段拼接：直道按当前朝向前进给定长度；圆弧按给定半径和角度向左（L）或向右（R）转。
*   中心线每 1 m 采样一次。路面、路基、地面带、护栏都沿采样点生成。
*   高度：从路径起点高度 0 开始，对平滑后的坡度（R-11 的窗口）沿里程积分。三条路径的任何位置高度都 ≥ 0（森林下坡段的坡度取 −5.9% 就是为了保证这一点）。
*   分段表里圆弧的"长度"一栏是四舍五入后的值，生成时以"半径 × 角度"为准；区段线的里程以各段精确长度累加为准，表中的里程数允许有 ±3 m 的出入。
*   主赛道不与自己相交，也不与环道相交：按本节数据生成后，主赛道上里程相差 200 m 以上的任意两点相距不小于 56 m（最近处是发卡弯的进出两条直道）；主赛道与环道除岔路口外相距不小于 60 m。
*   地面带：沿中心线向两侧各延伸 600 m 的平面，每 20 m 一个截面，颜色取所在环境的地面色。三个区段各是一张独立的网格，放在不同高度以免共面闪烁：森林（含出库路和环道）−0.05 m，冰原 −0.10 m，城市 −0.15 m；冰原的冰湖是另一张网格，高度 −0.03 m，只覆盖 I18 两侧。同一张网格自己折叠重叠的地方颜色相同，不需要处理。区段交界处两张地面带各自延伸到起点线之外 150 m。
*   "极限速度"一栏 = `sqrt(T-20 × 半径)`，按 T-20 = 3.0 g 算出，仅供阅读；实际以 R-12 为准。
*   环境物的摆放用固定随机种子（出库路与环道 1001，森林 2001，冰原 3001，城市 4001），每次运行结果相同。

### 6.3 车库（大本营）

*   内部尺寸：宽 14 m、长 24 m、高 6 m，占据 x 从 −7 到 +7、y 从 −10 到 +14 的范围。车停在原点（距后墙 10 m、距大门 14 m），车头朝北。北墙（y = 14）正中是 8 m 宽、5 m 高的大门，点火时已经敞开，门外是明亮的出库路。出库路的路面从大门（y = 14）开始画，门内是车库地面；出库路在门口处的 12 m 路宽两侧各有 2 m 被门框挡住，这一小段路面从 8 m 宽渐变到 12 m（门外 10 m 内）。
*   内饰：深蓝黑墙面，地面 `#4a5262`，地上两条金黄引导线（相距 3 m）从车的两侧通向大门；顶上三排暖白灯带（沿车库长边方向，自发光）；东西两面墙边各一排 4 个朱红工具柜（每个 2 × 0.8 × 1.8 m）；西墙上一块 6 × 1.2 m 的金黄色"STAR SPEED"字牌，中心离地 3.5 m。
*   人物和启动设备的位置见第 5.9 节。
*   基地外观（A-11）：车库外是一栋东西 40 m、南北 30 m、高 10 m 的深蓝黑平顶建筑，带朱红色屋檐线，占据 x 从 −20 到 +20、y 从 −16 到 +14 的范围；北面外墙就是车库的北墙（A-10 不再单独做这面墙，只有 A-11 做）；A-11 在这面墙正中开一个宽 8 m、高 5 m 的大门洞，A-10 的内部在门洞处是敞开的。

## 7. Game Feel and Tuning Table

### 7.1 手感目标（可检验的句子）

1.  **加速一波一波往上叠。** 每个档位内，越接近 7800 转推力越猛；升档瞬间推力一顿，随后下一波顶上来。和真车一样，低档转速升得飞快、一两秒就要升档，档位越高转速升得越慢。
2.  **升早了肉，顶到头炸。** 在 5000 转升档，能明显感到下一档推不动；过了红线换挡提示灯开始闪，顶在断油上速度不再上升、灯爆闪，1–7 档顶 2 秒引擎爆掉。
3.  **速度感分层升级。** 1–2 档画面基本正常；3 档起开始轻微拉长；车越快，两侧景物掠过得越快、拉得越长、视野越撑开，没有哪一刻是"切换"：到 285 km/h 左右（7 档 4500 转）拉线已经很明显，420 km/h 左右（7 档 6500 转）窗外已经看不到任何一个完整的物体，所有景物都变成一根根飞速掠过的线，像星际穿越时星星被拉成流星，只能靠这些线的走向判断前面的路往哪边弯；只有正前方一小块还看得清路，声音随速度渐渐被压住，音乐渐渐浮上来。这是普通开车那种"景物往后飞"的感觉被推到极限，不是另加的特效。
4.  **松油是"拖住"，降档是"一拳"。** 只松油门，车稳稳慢下来，对付发卡弯不够；每降一档，头往前点、转速跳起、引擎嚎叫、速度掉一截。
5.  **降档有节奏。** 降完一档要等指针落下来才能降下一档，从极速降到发卡弯是一串有间隔的"嚎—等—嚎—等"。
6.  **过弯余量越来越窄。** 第一段声音早早出现，第三段只有很窄的一条；要用点按油门才能稳在第三段上。
7.  **挣扎区救得回来，但很慌。** 车往外甩、尖叫、剧烈抖动的时候，立刻松油或降档能把它拉回来；犹豫一秒就飞出去。
8.  **失败狠，不拖沓。** 没有慢动作；爆炸之后 0.5 秒就能按油门键重来。
9.  **座舱始终清晰，外面越快越模糊。** 任何速度下转速表的刻度和数字都读得清。
10. **按着油门降档，车往前窜。** 高档低转推不动的时候，按着油门降一档：引擎嚎一声，转速跳到高处，头向后一仰，推力明显变大。
11. **停不下来。** 从极速到发卡弯要一连串降档才减得下来，其间每一秒都觉得"可能来不及"；没有任何一个键能让车立刻慢下来。

## 8. Art Direction and Asset List

### 8.1 风格

低多边形 3D 模型 + 轻微的像素化渲染（头脑风暴阶段的样张 E；样张里 480×270 的颗粒太粗，不采用）。

*   **造型**：形状夸张、棱角分明；不做圆滑倒角，不用平滑法线。
*   **明暗**：每个面一个纯色；受光面用本色，背光面用本色 × 0.72；只有这两级，没有渐变，没有投影。
*   **贴图**：不用贴图。颜色全部来自模型的顶点色；所有细节用几何体做出来（转速表的刻度和数字也是几何体）。
*   **描边**：物体轮廓和明显的折边有 1 像素宽（内部分辨率下）的描边，颜色深蓝黑 `#1b2233`，不是纯黑。
*   **像素化**：窗外世界以 T-45 的分辨率渲染，用最近邻方式放大到屏幕（1080p 下正好 2 倍）。座舱以 T-46 的分辨率渲染；1280×720 到 1080p 是 1.5 倍，直接最近邻放大会让像素宽窄不一，所以座舱画面先最近邻放大 3 倍、再线性缩小到屏幕尺寸（"锐利缩放"），得到大小均匀、边缘只有极轻微过渡的像素。座舱的颗粒始终比世界细，这个差别就是"隔着座舱看外面"的滤镜，不再另加扭曲或色调。屏幕分辨率不是 1920×1080 时，世界画面和界面也用同样的锐利缩放。
*   **限色与抖动**：每帧画面的每个像素都被压到当前环境的 16 色色板上。算法：在 sRGB 空间里按欧氏距离找出离该像素颜色最近的两个色板色 A（最近）和 B（次近）；把像素颜色投影到 A–B 连线上得到比例 t（0 = A，1 = B，限制在 0–0.5）；取该像素在 4×4 Bayer 矩阵里的阈值 b（0–1），若 t × 2 > b 则输出 B，否则输出 A。背光面（本色 × 0.72）因此呈现本色与相邻暗色之间的规则网点。天空的上下渐变同样呈现规则网点。
*   **座舱**：按真实赛车内饰的精致感来做，细节密度明显高于窗外：缝线、螺丝、面板分缝、表圈都用几何体做出。

### 8.3 渲染规则

1.  **两级明暗**：所有世界模型和座舱模型共用一种材质，输出颜色 = 顶点色 × 光色 × 明暗系数 × 亮度。明暗系数：面法线与光向的点积 > 0.15 取 1.0，否则取 0.72。不使用引擎的灯光，不接受也不投射阴影。顶点色 alpha 的约定：1 = 普通；0 = 自发光（不乘光色、明暗系数和亮度，直接输出顶点色；用于霓虹、灯带、流星、极光、转速表指针和数字、换挡提示灯亮起时）；0.5 = 颜色由外部传入（楼体色、贴纸材质色）；0.25 = 夜间自发光（白天版按普通面处理，金牌版里按自发光输出该环境的"夜间自发光色"；用于楼的窗格）。座舱另有两个独立的亮度参数：转速表亮度（点火前 0.3，点火后 1.0）和贴纸亮度（标题画面和结尾为 1.0，表示被小灯照亮；驾驶中跟随座舱亮度）。点火演出中，座舱亮度在 0.6–0.95 秒之间从 0.15 线性升到 1.0。
2.  **后处理顺序**（世界画面，在 T-45 分辨率下一次完成）：雾 → 径向拉线（V-02）→ 线化（V-03）→ 描边 → 压色板加抖动。
3.  **后处理顺序**（座舱画面，在 T-46 分辨率下）：描边 → 压座舱色板加抖动。座舱画面没有任何模糊和拉线。
4.  **描边判定**：世界画面有两种描边，都画成深蓝黑。轮廓描边：相邻像素的深度差超过该像素深度的 3%，只在深度 < 300 m 时画。折边描边：由深度重建的法线夹角超过 35°，只在深度 < 80 m 时画（远处的树和楼只有轮廓，不会糊成一片深色）。径向拉线强度 > 0 时，清晰区以外的描边按拉线强度同比例变淡。座舱画面只画轮廓描边（深度差超过 3%），不画折边描边；贴在表盘、仪表台表面上的细小几何体（刻度、数字、缝线、螺丝）凸起不超过 1 mm，所以不会被描边吞掉。
5.  **色彩校正**：模型进入游戏后，在森林白天灯光下受光面的屏幕颜色与色板色的差距不得超过 RGB 各通道 8/255；Blender 预览偏暗的问题通过"材质不做色调映射、灯光能量 1.0、环境不参与漫反射以外的计算"解决，不改色板。
6.  **不使用**：抗锯齿、动态阴影、屏幕空间反射、辉光、景深、运动模糊（引擎自带的那种）。

### 8.4a 模型预算与交付顺序（开发者的硬限制，优先于本规格里其他地方的素材数量）

*   **每个场景最多 5 个模型**（一个变体算一个模型）：森林（含出库路和环道）= 松树 2 + 岩石 1 + 森林门 1 = 4；冰原 = 冰山 2 + 冰锥 1 + 冰拱门 1 = 4；城市 = 楼房 3 + 龙门架 1 = 4；车库 = 车库内部 1 + 基地外观 1 = 2。
*   **其余建模合计最多 5 个**：座舱外壳（含仪表台，A-01 + A-02 合并成一个文件）、方向盘、转速表（含两盏灯）、人物（一个共用的方块人形，CEO / 保镖 / 技术人员只是缩放、配色、配件不同）、奖牌贴纸 = 5。
*   **不算建模的东西**（用代码生成，不进 Blender）：路面和路基、护栏 A-50、箭头牌 A-51、驶出标志牌 A-25、高架桥墩 A-44、云 A-60、远景环 A-61、金牌版氛围物 A-62。

### 8.7 Blender 脚本规范（所有来源为 B 的素材）

*   Blender 4.0，后台运行；一个入口脚本生成全部模型，也能单独生成某一类。
*   单位：1 = 1 米。模型原点在底面中心（环境物、人物、建筑）或转轴上（指针、方向盘）。Blender 里朝 −Y 为模型正面；导出 glTF 时勾选"+Y Up"，导入 Godot 后模型正面朝 +Z，所以摆放时（以及在导入设置里）统一绕竖轴转 180°，让正面朝 −Z。
*   只用顶点色上色（颜色属性名 `Col`），不建 UV，不用贴图，不用材质节点；导出时不带材质。
*   所有面为平直着色；不加倒角和细分修改器。
*   颜色只能取第 8.2 节列出的色值；背光面的暗色由游戏内材质计算，脚本里不要另涂暗色（色板中明确成对给出的颜色除外：森绿 / 暗绿、树干 / 暗树干、雪白 / 雪影，这些用于同一物体上的不同部位）。
*   自发光部位把顶点色 alpha 设为 0。
*   同一类的多个变体由同一个生成函数加不同的固定随机种子得到，保证风格一致、每次生成结果相同。
*   每个变体导出为独立的 glb 文件，文件名见第 11.7 节。
*   导出后必须在游戏里逐个检查比例、朝向和颜色（第 12 节阶段 5 的检查项）。

## 10. Audio

### 10.1 总则

*   引擎和轮胎用真实录音，在游戏里按转速和抓地分区分层混合；不用代码合成。
*   所有音频文件由开发者从免版权或已授权的音效库取得（如 Freesound 的 CC0 素材、Pixabay、Sonniss 的免费 GDC 音效包），按第 11.7 节的文件名放入 `assets/audio/`。格式：循环素材用 OGG Vorbis 并做成无缝循环（导入时勾选循环）；一次性音效用 WAV（16 位，44.1 kHz 或 48 kHz）。

### 10.4 引擎与轮胎的混合规则

**引擎主体（S-03）**

*   4 个转速层，默认录音转速 2000、3500、5500、8000（相邻两层的转速比不超过 1.75，保证交叉过渡时两层的音高对得上）；每层有"加油"和"松油"两个循环，8 个循环始终同时播放，只改音量和音高。
*   层音量：当前 rpm 落在相邻两层的录音转速之间时，这两层按等功率交叉过渡（低层音量 = cos(t × 90°)，高层 = sin(t × 90°)，t 是 rpm 在两层之间的位置 0–1）；其余层静音。rpm 低于最低层或高于最高层时只播那一层。
*   层音高：播放速率 = 当前 rpm ÷ 该层录音转速，限制在 0.5–1.6。
*   加油 / 松油：按住油门时"加油"套满音量、"松油"套静音；松开时相反，且"松油"套整体 −4 dB；0.08 秒内交叉过渡。断油期间"加油"套 −6 dB 并叠加 S-06；S-06 的音高按 R-09a 随过转计时器升高。
*   升档：T-09 期间全部引擎层静音（15 毫秒淡出、15 毫秒淡入），同时播放 S-04。
*   降档：播放 S-05，其播放速率 = 降档后 rpm ÷ 7000，限制在 0.8–1.3。
*   回火：松开油门的那一刻 rpm ≥ 6000 则播放一个随机的 S-07；两次回火至少间隔 1.5 秒，弯里连点油门时不会连成一片。S-04、S-05、S-09 的多个变体同样随机选取，不连续重复同一个。
*   外星嗡鸣（S-15）：音量固定 −18 dB；播放速率 = 0.5 + rpm ÷ 9000 × 1.5。在混音面板里把音量拉到 −60 dB 即关闭。
*   以上默认值全部能在混音面板里改（第 9.11 节）。

**轮胎**：四个循环同一时刻只播一个，按 R-13 的分区切换（30 毫秒交叉）；播放速率固定 1.0，但第三段的音量随 ratio 从 97% 到 100% 由 −3 dB 升到 0 dB。

**风声（S-14）**：音量按速度层级表；播放速率 = 0.8 + 车速 ÷ 720 km/h × 0.6。

### 10.5 总线与响度

| 总线 | 上级 | 内容 | 默认音量 |
| :-- | :-- | :-- | :-- |
| Master | — | 全部 | 0 dB |
| World | Master | Engine、Wind、SFX 的上级；挂一个低通滤波器 | 0 dB |
| Engine | World | S-03 – S-07、S-15 | 0 dB（全场最响） |

*   爆炸（S-21）播放时，Engine、Tires、Wind 在 0.1 秒内静音。

### 11.2 渲染结构

```
屏幕（1920×1080）
 ├─ 世界画面：WorldViewport（SubViewport，T-45，持续更新）的贴图，最近邻放大铺满
 ├─ 座舱画面：CockpitViewport（SubViewport，T-46，透明背景，独立的 3D 世界）的贴图，最近邻放大铺满，叠在世界画面上
 └─ 界面：CanvasLayer，960×540 画布放大 2 倍
```

*   世界和座舱各有自己的摄像机；每台摄像机前挂一个铺满视野的后处理四边形（全屏四边形，空间着色器，读取屏幕颜色贴图和深度贴图），按第 8.3 节的顺序完成该画面的全部后处理。
*   描边用的法线由深度贴图在着色器里重建（相邻像素的深度差求叉积），不依赖引擎的法线缓冲。
*   雾在世界后处理着色器里按深度混入（第 8.2 节），不使用 Environment 的雾；深度等于远裁剪面的像素（天空）不加雾。
*   天空：WorldEnvironment 的 Sky 使用自定义天空着色器，按仰角在上、下两色之间线性插值。
*   两级明暗材质：`unshaded` 的空间着色器，按第 8.3 节第 1 条的公式自己计算；光向、光色、亮度、夜间自发光色是材质参数，世界用一份材质、座舱用另一份，由 `environment_director.gd` 和 `cockpit.gd` 分别设置。面法线用顶点位置的屏幕空间导数求得，保证平直着色。场景里没有任何灯光节点。
*   环境物用 MultiMeshInstance3D 批量绘制，沿赛道每 500 m 一个分块，每个分块每种变体一个 MultiMesh；分块中心距摄像机超过 4500 m 时隐藏。楼房的楼体色通过 MultiMesh 的自定义数据传入：顶点色 alpha = 0.5 的面使用该颜色。
*   顶点色 alpha 的约定：1 = 普通；0 = 自发光；0.5 = 由外部传入颜色。
*   世界揭开（V-01）、挣扎暗角（V-06）是界面层里的全屏 ColorRect 加画布着色器，画在世界画面之上、座舱画面之下；它们的网点按 960×540 的像素网格对齐。大爆炸（V-05）画在座舱画面之上。白闪、白化、变暗画在全部画面和驾驶界面之上。
*   3D 文字（档位数字、驶出标志牌的文字）用 Label3D 的"裁剪透明"模式（alpha cut = discard）、关闭描边和阴影，使它们作为不透明物体渲染，从而进入后处理（描边、压色板、雾）。爆炸、流星、极光、霓虹全部是不透明网格。场景里不使用任何半透明材质；唯一的例外是小地图，它不在 3D 场景里，而是合成阶段的加色图层。
*   座舱画面的缩放：`CockpitRect` 使用锐利缩放着色器（第 8.1 节）。

### 11.2a 补充约定

*   **油门键的归属**：`CarSim` 只在驾驶状态（DRIVE_LOOP、DRIVE_MAIN、REENTRY 的控制交还之后）读油门；其余状态（信件、字幕、点火、失败跳过）由 `RunDirector` 读取并消耗这次按键，不传给 `CarSim`。第 5 条字幕推进时若油门键仍被按住，点火计时从"松开后再次按下"才开始。`pause`、`confirm` 也由 `RunDirector` 分发。
*   **跳过失败演出**：爆炸 0.5 秒后按油门键跳过时，画面在 0.1 秒内切黑、S-21 立即停止、失败原因条隐藏，之后按 R-21 从黑淡入。
*   **颜色与材质**：后处理着色器里先把屏幕颜色从线性转到 sRGB 再做色板匹配和抖动（色调映射设为线性）；顶点色按 sRGB 解释（`source_color`）。导入后的 glb 由 `scenery_spawner.gd` / `cockpit.gd` / `garage.tscn` 的脚本遍历所有 MeshInstance3D，统一设置 `material_override = flat2tone`。`garage.tscn` 里人物节点是 `Node3D`，实例化 `person.glb` 场景。FINISH 字样用 `Label3D`（alpha 裁剪，不用贴图）。
*   **挣扎外甩**：8°外甩的幅度 = 挣扎计时器 ÷ T-26 × T-38（随计时器渐增，救回时 0.3 秒回正）。座舱震动与镜头震动同时作用于座舱摄像机；速度层、轮胎分区、限速、挣扎的震动取最大值，不相加。
*   **重新开始一圈时的环境**：回到车库时车库用车库色板；驶出车库大门时才按存档读取金牌版并开始 2 秒过渡。进场回放才是"立即切到目标区段环境"。

*   **环境与回放**：进场回放（R-21）和"重新开始一圈"（R-22）开始时，环境立即切换为目标位置所在区段的环境（回放冰原就切到森林的环境，回车库就切到森林环境、金牌版也按存档），不做 2 秒过渡；之后正常越线才触发 2 秒过渡。
*   **Esc 的归属**：标题、邀请函、字幕、点火提示、结尾和白化期间，Esc 不响应（标题画面的 Esc 无效；要退出用"退出"按钮）；驾驶中、失败演出中、进场回放中按 Esc 暂停。窗口失去焦点只在这些驾驶相关状态下自动暂停。
*   **座舱画面的透明**：座舱 SubViewport 背景透明；座舱后处理着色器对深度等于远裁剪面的像素（窗外）输出 alpha = 0 且不画描边，其余像素 alpha = 1 并正常描边。阶段 2 先用一个测试方块验证"窗外透明、座舱有描边"。

```gdscript
# car_sim.gd —— 每个物理帧
func _physics_process(dt):
    if state == LOCKED: return         # 暂停、Game Over、失败演出
    if state == COASTING:              # 越过城市终点线后的白化期间：保持车速直行
        s += v * dt;  return
    if state == REPLAY:                # R-21：逐帧照搬记录里的路径、里程、车速、档位、油门
        apply_recorded_frame();  if 记录播完: emit replay_finished
        return
    push_frame_to_ring_buffer()        # R-21a：保留最近 T-56 秒
    read_input()                       # 油门、换挡（含缓存）
    rpm = max(idle, v / cut_speed[gear] * cut_rpm)
    if shifting:      a = 0，并推进换挡计时（松油降档在这段时间内另外均匀扣掉 T-15 的车速）
    elif throttle and rpm < cut_rpm:   a = peak_acc[gear] * torque(rpm) * uphill_factor
    elif throttle:    a = 0            # 断油
    else:             a = -coast(rpm) * downhill_factor
    v = max(0, v + a * dt);  s += v * dt
    update_overrev_timer(dt)           # R-09 → failed(2)；8 档不计时
    update_shift_lamp()                # R-09a
    kappa = track.curvature_at(path, s);  ratio = v / sqrt(grip / abs(kappa))
    update_tire_zone(ratio)            # R-13，带 0.5 个百分点的回差
    update_struggle_timer(dt)          # R-14 → failed(1)
    handle_path_switch()               # 出库路 → 环道；环道循环；岔路口 → 主赛道
    update_star_speed_flag()           # T-40：只用于 S-08 与 R-45 的判据；画面与音乐每帧直接读 v
```

### 实机试玩时调（tune during playtest）

1.  无刹车是否成立：发卡弯能否靠"松油 + 连降档"减下来（T-13、T-14、T-15）；不成立时由开发者决定怎么改（D1 里预留过加刹车键的后手；那会改变意图锚点里"没有刹车"的设定）。
2.  速度感分层方案是否成立（速度层级表、T-30）；不成立时换成"平滑渐变"或"全程夸张"（D6）。
3.  像素化颗粒度（T-45、T-46），以及拉线带颗粒后远处弯道是否看得清；小地图预看距离（T-52）。
4.  贴纸等级门槛（T-53）按开发者的实际成绩校准。
5.  星速音乐的风格（M-01）：听到实物后不合适就换。
6.  外星嗡鸣层（S-15）：不合适就在混音面板里关掉。
7.  能否在进弯前把速度调准、过弯正好贴在第三段（T-24、T-21、T-57）：贴不住时先加宽第三段或加大 T-21 的平滑窗口（让轮胎声更早响），最后才考虑把 T-57 降到 0.35。
8.  星速画面方案 A、B（T-48）：两个都试，选定一个。
9.  各条长直道的长度（R-47）：8 档到了断油就缩短那条直道。
10. 转头看弯的角度、触发距离和转头速度（T-36、T-39、T-39a），座舱视野的变化幅度（T-47）。
11. "操纵的快感"能否只靠油门和档位成立：demo 的成立标准有一半押在这上面，没有转向。阶段 1 结束时就先试（见第 12 节）。
12. 断油能当定速巡航用（顶 1.9 秒、松一下、再顶）：如果它成了某些弯的最优解，缩短 T-11 或让断油时车速缓慢下降。
